# AZ-104 Lab Reference Files

Infrastructure artefacts extracted from completed AZ-104 labs.
Terraform files represent the post-lab deployed state exported from Azure.
ARM templates are the original deployment templates used in the labs.

## Structure

```
az104/
  lab04/   VNet ARM templates and parameters (CoreServicesVnet, ManufacturingVnet)
  lab05/   Terraform main.tf extracted from deployed resources (VMs, NSGs, VNets, route table)
```
